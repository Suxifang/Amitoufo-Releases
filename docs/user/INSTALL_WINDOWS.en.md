# Windows installation and updates

Download from [Suxifang/Amitoufo-Releases](https://github.com/Suxifang/Amitoufo-Releases/releases). This public repository contains installers, update metadata and user documentation. The development source repository remains private; published downloads require no login.

Use `Amitoufo-<version>-win-x64-setup.exe` for installation or `Amitoufo-<version>-win-x64-portable.exe` for portable launch. Both use `%APPDATA%\MeetingCopilot` for personal data. Quit the old app and back up this folder before upgrading; do not delete it. Old r21 extracted files/shortcuts are not removed automatically.

Cloud operation requires your own transcription and answer services; Node.js and Python are unnecessary for ordinary cloud use. Local ASR requires a separate environment and models. Verify downloads with SHA256SUMS.txt. This beta is unsigned.

Beta.4 and earlier must manually install beta.5 or later once to switch update addresses. Install over the existing version; do not uninstall first or clear AppData. Later updates are available under “Update” below the app name: check, download, then quit and install. Portable builds remain manual. The public repository's “Source code” archives contain documentation only.

Ctrl+B shows/hides the running app. See the [complete Chinese manual](../USER_GUIDE.zh-CN.md).
