# 阿弥陀佛｜安装与使用手册

适用版本：**1.0.0-beta.5 · Windows x64**。手册更新：2026-11-02。

这是基于 MeetingCopilot 修改的桌面助手，提供语音转录、结合个人材料的回答、翻译和窗口采集保护。下载本项目 Releases 中的安装包后安装即可使用，不需要自己编译。首次使用需要配置自己的服务与 API Key。

**最快上手：下载 setup.exe → 安装并启动 → 配置服务 → 导入材料 → 选择模式 → 点开始。**

## 1. 应该拿哪个文件

从公开下载仓库 [Suxifang/Amitoufo-Releases](https://github.com/Suxifang/Amitoufo-Releases/releases) 下载，已发布的安装包无需登录。开发源码在另一个私有仓库维护；普通使用者无需访问源码仓库。

| 文件 | 用途 |
|---|---|
| `Amitoufo-<版本>-win-x64-setup.exe` | 推荐安装版，自动创建入口 |
| `Amitoufo-<版本>-win-x64-portable.exe` | 免安装启动；设置仍放在用户资料目录 |
| `USER_GUIDE.zh-CN.html` | 本手册的离线阅读页 |
| `SHA256SUMS.txt` | 下载文件的 SHA-256 校验值 |
| 下载仓库的 `Source code` | GitHub 自动打包的说明文档；不是应用源码，也不是安装包 |

## 2. 安装与启动

1. 准备 Windows 10／11 x64 电脑、可用收音设备，以及自己的语音识别和回答服务。云方案不需要额外安装 Node.js 或 Python；本地识别模型另行准备。
2. 下载 `setup.exe` 并运行，安装到当前用户。首次版本未做代码签名；遇到系统提示时，先核对来源和校验值，不要关闭系统防护或加入全局白名单。
3. 从“阿弥陀佛”桌面或开始菜单入口启动，首次按配置向导设置；已有 本地旧版 资料会使用相同的 `%APPDATA%\MeetingCopilot` 目录。
4. 在“设置 → 帮助与教程 → 关于阿弥陀佛”查看版本是否与下载页一致。
5. 选择免安装版时，退出旧进程后启动新文件。不要同时运行原版 MeetingCopilot 和本版，它们可能使用相同资料目录。

`Ctrl+B` 呼出／隐藏已运行程序，不能启动已退出的软件。点顶部“—”是隐藏，点“×”是退出。

可在 PowerShell 使用 `Get-FileHash <下载文件> -Algorithm SHA256`，与同一版本的 `SHA256SUMS.txt` 对照。校验一致只证明文件内容对应，不代表实际共享隐私或收音已经验收。

## 3. 配置语音识别和回答模型

**“听懂声音”和“生成答案”是两项服务。只配置回答模型的 Key，不代表已经配置好转录。**

### 使用本版内置云方案

1. 在首次向导点击“开始配置”。
2. “方案”页中的“低延迟推荐”是本版内置的**阿里云实时语音识别 + DeepSeek AI 回答**组合。这个名称是软件预设，不是零延迟或所有网络下的性能保证。
3. 在“语音识别服务”和“AI 回答服务”中分别填写自己的 Key。需要创建 Key 时，可点该卡片的“打开官方密钥页面”“打开官方文档”或查看教程，按服务商当前控制台完成。不要填写登录密码。
4. 分别点“保存并测试连接”，确认两项的结果，再完成向导。测试会调用对应服务，可能产生少量用量费用。
5. 进入主界面后，可在齿轮设置或底部服务状态中查看结果、重新测试。若是在普通设置页中修改，连接测试通过后还要点“保存”。

本版对应的预设模型名是：回答用 `deepseek-chat`，阿里云流式转录用 `fun-asr-realtime`；转录另有 `paraformer-realtime-v2` 预设。服务商的模型供应、账号权限和地区以其当前平台及连接测试为准，不要混用不同服务或地区的 Key。

### 已有其他模型或中转服务

在设置选择自定义服务，在高级设置填写服务商提供的 **Base URL、模型名和 API Key**，再测试并保存。文本回答接口需要与本程序使用的接口格式兼容；一个 GPT 文本模型的 Key 不会自动替代语音转录服务。截图问答还需要支持图像输入的模型。

### 只转录、本地识别与截图问答

| 需求 | 配置方法 |
|---|---|
| 暂时只要转录 | 向导选择“只使用实时转写，暂不配置 AI 回答”；此时不会生成回答 |
| 使用本地识别 | 进入高级配置，选本地后端，并按源码部署资料准备对应环境与模型；本运行包没有附带大型模型权重 |
| 语音问答即可 | 保持“纯文本”，不必配置视觉服务 |
| 要让模型看截图 | 在设置中配置并测试视觉模型，切换到多模态后使用框选截图问答 |

如果提示未配置、余额不足、无权限或模型不存在，先解决相应服务的问题；反复点击“开始”不能代替服务配置。

## 4. 导入简历、岗位信息和详细背景

1. 在没有共享／录屏时准备材料。如果已经开始共享，先暂停共享／录屏，再关闭助手的“隐身”。
2. 选择或新建一个会话，可按公司和岗位命名。
3. 点击“简历”导入个人背景，点击“JD”导入岗位要求。支持 `.md`、`.markdown`、`.txt`、`.docx` 和可提取文字的 `.pdf`；扫描图片 PDF 不会自动变成可用文字。
4. 检查按钮显示的文件名，确认是当前会话所需材料。然后恢复“隐身开”，再继续共享。

**服务配置保存在这台电脑，通常只配置一次；简历和 JD 按会话保存。** 回到原会话不需要每次重传；换公司或岗位时建议新建会话，并核对该会话的两份材料，避免沿用上一家的背景。

“简历”也可以是一份详细的个人背景 MD：写明教育、项目、实习、自己具体做了什么、遇到的问题、采取的办法、结果和适合追问的细节。岗位职责和任职要求放在 JD 文件。真实经历、准备尝试的做法、网上面经要分别标清，避免参考范文被当作本人经历。

程序会按当前问题选取有限的材料与对话上下文，并非每次都完整理解所有文件。重要信息尽量用清楚的标题和具体事实组织。回答长短与表达由共用逻辑指导，也仍受材料、题目和所选模型影响。

## 5. 电脑线上会议怎么用

适合对方的声音从**这台电脑的会议软件**传来的情况。

1. 先在会议软件确认，电脑扬声器或耳机能正常听到对方。再在助手选择电脑模式。
2. 选择正确的本人麦克风，点“开始”。正常配置下会同时启用系统声音转录、持续答和本人麦克风记录。
3. 对方提问经系统声音转录后，程序识别为问题时自动生成答案；并非每一句声音都会回答。漏判时可以点“答最新题”、按 F8，或在转录页点原题旁的“答”。
4. 本人麦克风转录主要作为后续对话的上下文，**不会自动把自己的每一句回答再次拿去答**。不需要记录自己时，可以单独关闭麦克风。
5. 点“持续答”可暂停／恢复自动回答，转录仍继续；点“停止”才会统一停止收音和自动回答。

建议用耳机，减少对方的声音再次进入本人麦克风。系统声音来源也可能包含播放器、其他网页等声音，测试和使用时应留意其他应用的播放情况。

## 6. 手机播放题目怎么用

适合题目从**手机扬声器**播放，由电脑麦克风收进来的情况。手机本身不安装本程序。

1. 手机开启外放，在电脑助手选择“手机面试·麦克风收题”。
2. 确认所选麦克风能收清手机声音，点“开始”。本模式默认持续转录，**默认不开持续答**。
3. 题目说完、自己开口回答之前，按一次 **F8**，或点“答最新题”。程序提交所收集的题目并显示答案。
4. 如果当前文字还在转录，快捷键会等待当前一句定稿，最多 8 秒；无需连续按。若等待超时，先看转录是否完整，再重新提交。
5. 自己回答时不需要反复切换录音开关。后续发言仍会被转录，但不会改写已经提交的题目。下一道题按同样步骤操作。

**同一个麦克风同时收到手机声音和本人声音时，当前版本不能可靠分辨说话人。** 未按 F8 的文字也不会自动确认为“本人回答”；它保留为说话人未区分的对话参考。因此，若自己已经开始回答，再按“答最新题”可能取到自己的话，此时应到转录页找原题旁的“答”。

手机模式也可以主动开启“持续答”，但它依赖文字规则判断问题，存在把自己的话当题目或漏答的情况。为减少混淆，默认采用题目结束后按 F8 的方式。

## 7. 常用功能与快捷键

| 控件／按键 | 作用 |
|---|---|
| 开始／停止 | 启停当前模式的收音；停止时结束后续自动答 |
| 持续答 | 自动识别所选来源的问题并回答；再次点击暂停自动答，转录继续 |
| F8 | 提交最新题目；电脑与手机模式都可使用，可在设置修改 |
| 转录旁“答” | 对指定片段生成回答；重复提交同一片段会定位已有答案 |
| 转录旁“译” | 显示中文翻译，译文不作为新的对话上下文 |
| 答案／转录 | 在同一个窗口切换阅读内容 |
| 底部输入框 + 回车／答 | 使用与语音相同的面试回答逻辑，提交输入的题目；回车不是默认全局答题键 |
| 纯文本／多模态 | 选择回答模型类型；多模态及截图问答需要视觉服务 |
| Ctrl+Shift+S | 默认框选截图问答快捷键，需要先配置可用的视觉服务 |
| Ctrl+B | 隐藏／呼出已经运行的助手窗口 |
| 右上角 — | 隐藏窗口，程序仍运行；用 Ctrl+B 或再次打开启动入口找回 |
| 右上角 × | 退出程序；退出后快捷键不再生效 |
| 隐身开／关 | 控制助手窗口的采集保护，与隐藏窗口是两件事 |
| 穿透开／关 | 控制正文区域的鼠标点击是否交给下面的应用 |
| 回到最新 | 回到最新答案并恢复跟随 |
| 尺寸 | 选择窄版／标准，或输入自定义宽高，保存后下次继续使用 |
| 顶部空白处／名称区域按住左键 | 拖动窗口；顶部按钮仍用于点击操作 |
| 复制 | 复制相应答案 |

快捷键注册失败时，先检查是否被其他程序占用，再在设置更换。Windows 默认隐藏托盘图标；呼出快捷键注册失败时会保留托盘作为恢复入口。

### 穿透与阅读

“穿透开”时，正文和空白处的点击会落到下层应用，开始、译、答、复制等控件仍可点击。鼠标放在助手面板上滚动时，滚轮用于阅读助手内容；向上滚动会暂停跟随，点“回到最新”恢复。需要划选助手文字时，先关闭穿透。

新题在跟随状态下定位到题目开头，答案生成中不会一直把阅读位置推到最底部。在回看历史或查看转录时，新答案可能不会抢走当前视图；此时用“回到最新”查看。穿透区的光标由下层应用决定，程序没有把整个系统光标隐藏。

## 8. 隐身、共享屏幕与数据去哪了

“隐身开”用于保护助手窗口及其内部控件不被支持该机制的采集方式捕获；**不能保证所有会议软件、系统版本和截图方式都完全不可见**。换电脑、会议软件或采集方式后，需要重新测试。

开始正式共享前，用无敏感内容的背景检查：截图、录屏、隐藏后呼回、按钮悬停、窗口尺寸调整和实际接收端。腾讯会议与飞书需要分别核对，自己的桌面看起来正常不代表对方收到的画面正常。发现黑框或泄漏时应先停止共享，再定位原因。

系统文件选择框、外部浏览器、输入法候选框、系统通知和任务管理器不属于主窗口的内部内容。导入材料应在共享前完成；隐身中系统文件选择框会被阻止。窗口保护不等于在任务管理器中隐藏进程，鼠标也可能被会议软件单独采集。

| 数据 | 保存／发送到哪里 |
|---|---|
| 设置、会话及导入材料 | 当前 Windows 用户的 `%APPDATA%\MeetingCopilot` |
| API Key | 保存在本机，优先使用系统加密能力；系统能力不可用时程序会提示弱保护，不能把配置文件当作无敏感信息 |
| 云端转录的音频 | 发送给自己配置的语音识别服务 |
| 云端模型回答 | 发送题目、所需背景及有限的对话上下文给自己配置的模型服务 |
| 截图问答 | 选定的图像内容发送给自己配置的视觉模型服务 |

运行包不携带分享者的 Key、简历、JD 或个人会话。使用后产生的用户资料也不要再混入分享文件夹。

## 9. 常见问题

| 现象 | 先这样检查 |
|---|---|
| 关了小窗找不到 | 按 Ctrl+B；不行就再次打开自己的桌面／开始菜单入口 |
| 显示停止／录音中，却没有文字 | 确认模式、输入设备与实际声音来源；看底部转录服务是否可用。录音中只说明采集已启动，不证明识别成功 |
| 电脑模式听不到手机对面说话 | 先确认电脑会议端确实加入音频、能听到对方；手机有声音不代表电脑已收到系统音频 |
| 手机模式有文字，没有答案 | 默认是手动答；题目完整后按 F8。若按钮也无效，检查回答服务状态 |
| 已开持续答，但一句话没回答 | 可能没被判为问题、还在等待定稿、被去重或请求失败；先用该题旁“答”区分，不直接认定模型坏了 |
| 点答后好像没更新 | 点答案页和回到最新，检查是否停在旧记录；同一题重复提交可能定位已有答案 |
| 按 F8 没反应 | 检查是否有完整题目、回答服务是否可用、快捷键是否提示冲突；部分键盘需配合 Fn，也可在设置换组合键 |
| 想直接拖边框改大小却不行 | 隐身时原生边缘缩放锁定，使用右下角“尺寸”调整 |
| 不能选中助手文字 | 先关闭穿透，或直接点击复制 |
| 导入文件被阻止 | 暂停共享／录屏，关闭隐身再导入；完成后恢复隐身 |
| API 测试失败 | 按具体提示检查 Key、账号权限、余额、模型名、服务地区或网络；语音与回答两项分别测试 |
| 本地模型一直加载或启动失败 | 本地环境／模型可能未准备好；查看部署资料，或配置云转录后先测试完整流程 |
| 答案总是重复或很空 | 检查当前会话的简历／JD是否正确、转录是否完整、材料是否只有套话；共用提示不能保证所有模型都自然 |
| 睡眠／锁屏后没有继续录音 | 确认设备后重新点开始；程序不会自动恢复旧收音任务 |
| 一启动就出现别人的材料 | 停止使用并检查来源及本机旧资料；干净运行包不应携带他人的个人配置 |

仍无法解决时，记录**版本、所选模式、操作步骤、实际现象及服务错误代码**，可从帮助页打开诊断信息。避免把 API Key 或整份个人会话当作普通日志发给别人。

## 10. 更新、备份与移除

- Windows 安装版从 beta.2 起支持应用内更新；beta.3 起点击左上角名称下方的“更新”（旧版入口为设置 → 帮助与教程 → 软件更新），再点击“检查更新”，发现新版后点“下载更新”，校验完成再点“退出并安装”。先停止收音、等回答完成；会话保存并清理收音进程后才安装和重开。正常退出不会自动安装。
- **beta.4 及更早版本需要从公开下载页手动覆盖安装一次 beta.5 或更高版本**，旧地址不会自动切换。无需先卸载，不要清理 AppData；这次切换后，后续使用应用内入口。免安装版继续手动更换 portable 文件。
- 检查更新仅在点击后访问公开 GitHub，不上传 Key、材料或会话。beta 版接收后续 beta 和正式版；正式版默认只接收正式版，禁止自动降级。下载按发布的 SHA-512 校验，安装前再次校验；校验失败不执行文件。
- 检查或下载失败可重试，当前程序仍可使用；也可点“打开发布页”手动下载。安装器未做代码签名，校验值与 GitHub 账号来源仍是当前信任边界。
- 程序与个人资料分开保存。更新程序通常不用重填 Key、重传原会话材料；升级前可自行备份 `%APPDATA%\MeetingCopilot`，备份只留自己使用。
- 换电脑时重新配置 Key，并按需要重新导入材料；密钥的本机加密不能靠复制资料可靠迁移。
- 不再使用免安装版时，先退出并删除自己的程序目录与快捷方式。个人资料仍保存在上述 AppData 目录；只有明确想删除历史和配置时再自行清理该目录。

## 12. 本版验证情况

本版以本地 r21 为功能基线；r21 历史记录包括 655 项单元测试、8 项 Python 测试、编译及定向后台回归。首个 GitHub 版本另行执行检查和安装包验收，以 Release 说明和 BUILD-INFO.json 为准。

这些后台检查主要使用隔离资料和模拟输入。真实语音云服务、可见截图／录屏、腾讯会议／飞书接收端、长时间真实使用和另一台电脑运行需要分别实测。本手册不把验证范围外的效果写成保证。

实现与历史实测证据保留在私有维护资料中；公开版本的验证范围和未测事项写在对应 Release 说明里。
